# CV — Максим Иванченко

Полноширинная веб-страница с резюме на русском языке, готовая к публикации на GitHub Pages. Страница не требует сборки, JavaScript или внешних зависимостей.

Вёрстка выполнена в стиле открытого MIT-лицензированного шаблона [Academic Pages](https://academicpages.github.io/): верхняя навигация, профильная колонка и основной контент. Реализация использует только один HTML- и один CSS-файл, без Jekyll, JavaScript и внешних зависимостей. Условия лицензии приведены в `THIRD_PARTY_NOTICES.md`.

## Локальный просмотр

```bash
python3 -m http.server 8000
```

После запуска откройте [http://localhost:8000](http://localhost:8000).

## Публикация на GitHub Pages

1. Закоммитьте файлы и отправьте ветку `main` на GitHub.
2. В репозитории откройте **Settings → Pages**.
3. В блоке **Build and deployment** выберите **Deploy from a branch**, ветку `main`, папку `/ (root)` и нажмите **Save**.

После публикации сайт будет доступен по адресу `https://<username>.github.io/<repository>/`.

Исходный файл `1_resume.txt` содержит персональные данные и исключён из Git через `.gitignore`.
